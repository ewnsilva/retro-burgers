# ⚠️ Em construção

Trata-se de um projeto que representa um cardápio virtural de uma lanchonete, com temática dos anos 80, que contêm funcionálidades como filtro de búsca, seleção de categórias, adição de produtos a uma lista de pedidos (carrinho), escolha de quantidade, constumização de hamburguer, dentre outras funções.

## Tecnologias

HTML, CSS e Javascript, Typescript, React, Node.js, Axios, Material UI e Styled-Component
